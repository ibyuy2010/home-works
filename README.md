 # Student Grade Checker

## Project Description
A simple Python program that asks for a student's name and grade, then determines whether the student passed or failed.

## How It Works
1. Enter the student's name.
2. Enter the student's grade.
3. If the grade is 60 or above, the program displays "Passed!"
4. Otherwise, it displays "Failed!"
